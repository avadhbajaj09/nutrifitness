# Weekly report prompt

Write the weekly report for nutrifitness.ch from the supplied measured data only. Do not guess missing values: write "no data".

## Structure (short, bullets)
1. **Headline** (2 sentences): what moved and why.
2. **Numbers vs last week**: indexed/submitted pages, Merchant approved/disapproved, GSC impressions/clicks/CTR/avg position, keywords in top 3/10/20, CWV pass rate, referring domains, GBP views/calls, reviews, AI-citation rate, orders/revenue.
3. **Wins** (max 5) and **Losses** (max 5) with URL, keyword, delta, probable cause.
4. **Work done**: tasks completed, tasks waiting for approval, tasks blocked.
5. **Issues**: open critical/high with owner and age.
6. **Spend**: agent cost this week vs cap.
7. **Next 3 actions** recommended to the orchestrator.
Tone: direct, honest, no hype.
